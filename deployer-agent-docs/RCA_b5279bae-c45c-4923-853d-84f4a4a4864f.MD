## 3. Live login failure — ROOT CAUSE (credential mismatch, NOT a server fault)
Evidence from the pre-deploy active run logs:
- `POST /api/auth/login` → **401 Unauthorized ×3**. **No 502** (OTP send failure), **no 500** (crash), backend healthy throughout.
- In `server.py` the login handler returns `401 "Invalid email or password"` only when the email is unknown OR `verify_password()` fails. So the failing logins are being rejected at the **password step** — the submitted password does not match the stored `password_hash`.

Why the password won't match — the decisive finding in `seed_admin()`:
```
existing = await db.users.find_one({"email": admin_email})
if existing is None:
    # create with hash_password(ADMIN_PASSWORD)
else:
    # Keep name/role in sync with env; do NOT overwrite password if already changed by admin
    update_one(..., {"$set": {"name": admin_name, "role": "Admin"}})
```
- The primary admin `arunenterprises2023@gmail.com` already exists in `users` (created **2026-09-28**), and `ADMIN_EMAIL` matches it.
- The previous deploy (run `62b11a6e`, 2026-10-26) was triggered by a **secret_change**. If `ADMIN_PASSWORD` was edited in the Secrets tab expecting it to reset the login, that **does nothing by design** — `seed_admin` never overwrites an existing admin's password. The stored `password_hash` is still the original/last in-app value, so logging in with the *new* secret value yields 401.

Additional login behavior (so E1/user don't chase wrong paths):
- Primary SuperAdmin (`email == ADMIN_EMAIL` = `arunenterprises2023@gmail.com`) **skips OTP** — login is password-only.
- All OTHER users (e.g. the three `@arunenterprises.online` accounts) require a 6-digit **email OTP** via `EMERGENT_EMAIL_KEY`. Key is present and no 502 was observed, so OTP sending is not currently implicated — but if a user reports "OTP not arriving," that is a separate email-delivery check.
- Rate limit: **5 failed attempts in 15 min → 429** lockout for 15 minutes. Repeated wrong-password retries will temporarily lock the account.
